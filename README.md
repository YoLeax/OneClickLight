# OneClickLight

OneClickLight is a Beat Saber PC mod for saving and applying groups of visual
settings with a single click. It brings base-game visual options and supported
mod settings together in one Gameplay Setup tab.

OneClickLight supports Beat Saber 1.39.1 through 1.40.8.

## Configurations

The mod starts with three configurations: `ON`, `Half-ON`, and `OFF`. You can
keep any custom number of configurations from 1 up to a maximum of 12.

Configurations can be:

- Created and deleted
- Moved up or down
- Renamed
- Assigned a custom button color

Each configurable setting has an override toggle on its left. When an override
is disabled, applying that configuration leaves the corresponding game or mod
setting unchanged.

## Configurable Options

### Base Game

- Environment Effects
- Expert+ Environment Effects
- No Texts & HUDs
- Advanced HUD
- Arc Visibility
- Override Default Environments
- Override Default Colors
- Color Type Override (`All` or `Notes Only`; Beat Saber 1.40.0 and later only)

### SongCore

- Allow Custom Song Note Colors
- Allow Custom Song Obstacle Colors
- Allow Custom Song Environment Colors

### Chroma

[Chroma](https://github.com/Aeroluna/Heck) is optional. This section is only
shown when Chroma is installed and loaded by BSIPA.

- Use Custom Environment
- Disable Environment Enhancements
- Disable Note Coloring
- Disable Chroma Events
- Force Zen Mode Walls

### Extra

The Extra section is only shown when at least one of its optional mods is
installed and loaded by BSIPA. Each option is shown only for its corresponding
installed mod.

- JDFixer Enabled — requires JDFixer
- NoAutoExposure Enabled — requires [NoAutoExposure](https://github.com/YoLeax/NoAutoExposure)
